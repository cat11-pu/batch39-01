# GSB Bugfix Task
## 题面
程序化生成的地图边缘总是对不上：草地和沙地的接缝处出现一条纯色带，因为拼块只按中心颜色选，没有看四条边的颜色；地图边界要求外侧统一是海，生成器却把内陆块放到了边上；同一个种子跑两次结果不同，回放和每日挑战全乱；遇到三面约束冲突时直接放弃整张图，没有回溯；带权重的候选块每次都选权重最高的，地图千篇一律；一格大小的地图和一百乘一百的地图走了两条不同分支；四个方向都没有匹配块时抛了未捕获异常；角落块只检查了两条边；允许重复使用同一块时，相邻同款块形成明显图案；地图中间挖空一块后，周围四格的约束没有重新计算；候选列表为空和候选列表只有一个的情况没有区分；权重为零的块仍然被选中；生成失败后没有返回冲突位置。tile_wang_solver.py 的 TileWangSolver 要按边约束求解整张地图：每个拼块声明上下左右四条边的颜色和权重，边界格先钉死外侧颜色；从约束最多的格子开始填，候选按权重做确定性抽样，种子固定时结果固定；冲突时回退到上一个决策点，记录回退次数；候选为空时返回冲突坐标和涉及的方向，而不是抛异常；允许配置是否禁止相邻同款；挖空区域按障碍处理，周围约束重新计算；一乘一和超大图走同一套逻辑；权重为零的块不进入候选；求解结果和冲突报告分开返回。test_tile_wang_solver.py 的十五个用例现在全部失败，覆盖边颜色、边界钉死、种子稳定、回溯、权重抽样、大小地图一致、无候选、角落、相邻同款、挖空、单候选、零权重、冲突位置、回退计数和报告分离。

## 运行方式
```bash
python -m pytest tests -q
```
