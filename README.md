# GSB Bugfix Task
## 题面
内核侧要上线一批过滤程序，审核工具却把明显有问题的字节码判成通过。跳转指令的目标落在程序外，审核器只检查了操作码；向后跳转形成循环，没有做可达性分析；寄存器在写入之前就被读取，代码默认初值为零；栈访问偏移超出范围，负偏移被当成无符号数；除法指令没有检查除数为零；辅助函数编号不在白名单里也放行；程序没有退出指令，执行会落进数据区；跳转偏移按字节算还是按指令算搞混，边界差一条；不可达指令里藏着非法操作，审核器仍然逐条检查；程序长度超过上限没有截断。bpf_verifier_lite.py 的 BpfVerifierLite 要做控制流和数据流的双重检查：逐条解码指令，校验操作码、寄存器编号和立即数范围；跳转目标必须落在指令边界内，禁止向后跳转形成的环；按基本块做可达性分析，只检查可达指令；寄存器使用前必须有定义，栈访问按指令宽度检查上下界；除法和取模检查除数为零；辅助函数只允许白名单编号和参数个数；程序必须以退出指令结束；指令总数、跳转深度和栈深度都有上限；结果返回错误列表、基本块数量和最大栈深。test_bpf_verifier_lite.py 的十五条断言现在全部失败，压跳转越界、向后循环、未初始化寄存器、栈越界、除零、辅助函数、缺少退出、偏移单位、不可达指令、长度上限、操作码、寄存器编号、基本块、错误列表和栈深统计。

## 运行方式
```bash
python -m pytest tests -q
```
