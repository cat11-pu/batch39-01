# GSB Bugfix Task
## 题面
团队副本的仇恨表最近天天被团长投诉。治疗加血产生的仇恨和伤害仇恨用了同一个系数，奶妈一开大招就把首领拉走；嘲讽写着持续三秒，实际只改了当前目标，三秒内再有人打一下又抢回去；远程职业在四十米外开怪，仇恨直接按满值算，没有距离修正；视野外的玩家仍然在仇恨列表里，首领隔着墙追人；两个目标仇恨只差一点时每帧来回切换，近战跟着跑断腿；仇恨衰减只在脱战时生效，长时间战斗里越叠越高；团灭后仇恨表没有清空，下一把开局就带着旧数据；宠物和主人的仇恨分开算，宠物死了仇恨凭空消失；同一个单位被重复加入列表两次，移除时只删了一条；免疫嘲讽的首领仍然被强制改目标。aggro_threat_table.py 的 AggroThreatTable 要维护一份可解释的仇恨：伤害按实际扣除生命值计一分，治疗按有效治疗量乘系数，过量治疗不计；嘲讽在持续时间内强制目标，结束后恢复按仇恨选择，期间产生的仇恨照常累计；远程攻击按距离分段打折，视野外不再新增仇恨但保留旧值并逐渐衰减；切换目标需要超过当前目标百分之一百一十才生效，避免抖动；脱战和长时间未受攻击都触发衰减，衰减速率可配置；单位死亡、离场、重复加入都要幂等处理，宠物仇恨按比例归并给主人；团灭或重置清空全表；查询返回排序后的列表和每个单位的仇恨来源，快照不能被外部改坏。test_aggro_threat_table.py 的十五项检查目前均未通过，压治疗仇恨、嘲讽时长、远程距离、视野、目标抖动、衰减、团灭清空、宠物归并、重复加入、免疫嘲讽、过量治疗、仇恨来源、排序、重置和快照隔离。

## 运行方式
```bash
python -m pytest tests -q
```
