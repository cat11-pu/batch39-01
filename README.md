# GSB Bugfix Task
## 题面
竞技场征召模式一上线，选人顺序就被玩家抓到漏洞。禁选阶段两边同时禁了同一个英雄，系统只记了一次，后面少禁一个；选人按固定先手，没有按局数轮换；超时自动选直接挑了第一个可选英雄，没有按位置偏好；掉线玩家的选择被跳过，轮到时直接卡住；无畏模式里已经用过的英雄仍然能选；角色互换请求在选人结束后还能生效；非法操作比如重复禁选没有拒绝，状态被写坏；阶段跳过时没有补足禁选数量；时间银行用完后仍然允许操作；回放里的操作顺序和当时不一致；最终阵容没有校验人数和位置。arena_ban_pick.py 的 ArenaBanPick 要推进完整的征召流程：按配置的禁选数量和先后手顺序生成操作序列，支持逐局轮换先手；每次操作校验阶段、阵营、英雄是否已被禁或已选，非法操作拒绝且不改变状态；超时自动选择按预设偏好列表取第一个可用项；掉线玩家由托管按同样规则代选；无畏模式维护已使用集合；角色互换只在允许的阶段生效；阶段跳过要补齐数量；时间银行按操作扣减，耗尽后只能自动选择；回放记录每个操作的序号、阵营和结果；结束前校验双方人数、位置和英雄唯一性。test_arena_ban_pick.py 的十五个用例现在全部失败，压重复禁选、先手轮换、超时偏好、掉线托管、无畏模式、角色互换、非法操作、阶段跳过、时间银行、回放顺序、最终校验、禁选数量、状态不变、代选规则和唯一性。

## 运行方式
```bash
python -m pytest tests -q
```
