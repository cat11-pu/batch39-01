# GSB Bugfix Task
## 题面
网关开始解析合作方发来的二进制消息后，进程隔几天就被一条畸形报文打挂。变长整数连续十个字节都是高位继续，解析器没有上限，直接读越界；字段编号写成零，代码当成普通字段继续解析；长度前缀声明的长度比剩余字节还大，切片时抛异常；嵌套消息递归没有深度限制；重复字段和映射条目混在一起，后者覆盖前者；未知字段被当成错误丢弃，兼容性直接断掉；组类型的老式写法没有识别，标签错位；字符串字段没有做编码校验，下游拿到非法字节；同一条消息里同一字段出现两次，取值取决于先后；报文末尾多出几个字节也照收。protobuf_wire_fence.py 的 ProtobufWireScan 要做带边界检查的线格式解析：变长整数最多十个字节且拒绝溢出；字段编号必须大于零且不在保留区间；长度前缀不得超过剩余长度，嵌套深度和总字节数有上限；线类型只接受已知集合，组类型要么完整解析要么明确拒绝；未知字段保留原始字节而不是丢弃；字符串和嵌套消息做编码校验；重复字段按出现顺序保留，映射条目按键合并并检测冲突；末尾多余字节报错；结果给出字段列表、未知字段和消耗字节数。test_protobuf_wire_fence.py 的十五项检查现在全挂，压变长溢出、字段编号零、长度越界、嵌套深度、重复字段、映射冲突、未知字段、组类型、编码校验、末尾多余、保留区间、总字节上限、线类型、顺序保留和消耗字节。

## 运行方式
```bash
python -m pytest tests -q
```
