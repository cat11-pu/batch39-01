# GSB Bugfix Task
## 题面
贴图在远处出现严重闪烁，近看又有细密的噪点，美术怀疑是自动生成的多级纹理有问题。排查发现生成器只做了简单的隔点采样，奇数尺寸的最后一行一列被丢掉；宽高不是二的幂时，每一级的尺寸取整方向不一致，最后一级不是一乘一；带透明通道的贴图没有按预乘方式平均，边缘出现黑边；色彩空间是 sRGB，生成时却按线性值直接平均，整体偏亮；每一级的舍入方式不同，同一张图两次生成校验和不一样；数组贴图的每个层各自生成，层与层之间串了数据；最小尺寸被硬编码成四，小于四的贴图直接报错；生成过程修改了输入数组；带边框的图集区域把相邻图的内容也平均进来；三级之后没有继续生成，采样器却请求更高级。mip_chain_builder.py 的 MipChainBuilder 要从一张源图生成完整多级链：每一级按二乘二盒式滤波降采样，奇数尺寸先补边再取整，最终必须到一乘一；sRGB 贴图先转到线性空间平均，生成后转回，透明通道按预乘处理；数组贴图逐层独立；最小尺寸可配置但不能大于源尺寸；采样时按图集子区域裁剪，不越界；舍入用固定规则，同一输入得到同一校验和；不修改源数组，返回每一级的尺寸、数据和校验和；源图为零尺寸或超过最大边长时给出明确错误。test_mip_chain_builder.py 现在十五项比对全部失败，涉及奇数尺寸、非二的幂、透明黑边、sRGB、舍入一致、数组串层、最小尺寸、输入不变、图集越界、级数完整、盒式滤波、一乘一、校验和、零尺寸和超大边长。

## 运行方式
```bash
python -m pytest tests -q
```
