# GSB Bugfix Task
## 题面
角色的序列帧动画一放到高刷屏就快进，换到低端机又变慢，同一个技能在两种设备上节奏完全不同。现在的播放器按渲染帧计数，每帧固定推一张图，完全没有看每张图的持续时间；循环模式只会从头再来，策划要的往返播放没有；动画事件按帧号触发，跳帧时事件直接丢了；暂停后继续播放会回到第一帧；拖动进度条到两张图中间时，显示的是后一张，和音效对不上；单帧动画被当成零长度，播放器卡死；负时间没有处理，倒放直接越界；可变帧率下累计误差越来越大，十分钟后偏了两秒；两张图之间需要混合时没有权重；播放结束回调在循环模式下仍然触发；同一帧里连续 seek 三次，事件触发了三次。flipbook_timeline.py 的 FlipbookTimeline 要按时间轴而不是帧号推进：每帧带持续时间，累计时间决定当前帧和帧内权重；支持单次、循环和往返三种模式，往返在两端各停留一个持续时间；事件绑定在时间点上，跨帧时按时间顺序触发且只触发一次，seek 后不补发越过的事件；暂停冻结时间，恢复从冻结处继续；seek 接受任意时间，负数和超过总长按模式回绕或夹紧；单帧和零持续时间有明确语义；可变帧率按真实时间累加，不按帧数；输出当前帧、下一帧、混合权重和本步触发的事件列表。test_flipbook_timeline.py 有十五处失败，盯着高速率、低端机、往返、事件丢失、暂停恢复、拖动、单帧、负时间、长时漂移、混合权重、结束回调、连续 seek、零时长、可变帧率和事件顺序。

## 运行方式

```bash
python -m pytest tests -q
```
