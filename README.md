# GSB Bugfix Task
## 题面
开放世界里的模型在远处会突然从精细档跳到粗糙档，玩家一眼就能看见。现在的选择只看距离，同一个距离阈值对所有模型一视同仁，大模型和茶杯用同一档；屏幕分辨率变化后阈值没跟着变，四K屏上跳变更明显；相机视场角改了也没有重算投影误差；模型刚好在视锥边缘时被剔除，转身又出现；两个相邻档位的误差接近时来回切换，每帧都在抖；切换瞬间没有过渡，几何直接替换；强制指定档位的调试开关被距离逻辑覆盖；距离为零时除零；超远距离没有兜底档；场景里两百个模型逐个算投影误差，主线程超预算。lod_error_select.py 的 LodErrorSelect 要按屏幕空间误差选档：输入模型包围球、各档的几何误差、相机位置与朝向、视场角和分辨率，算出每个档位投影到屏幕上的像素误差；选满足误差上限的最粗档，误差相同取面数少的；加入滞回区间，误差在阈值附近时保持当前档直到超出缓冲区；档位之间给出交叉淡入权重，切换不闪；视锥外的模型返回剔除状态，边缘保留保守判断；强制档位开关优先级最高；距离为零和相机在包围球内单独处理；超远距离落到最后一档；每帧只算可见模型，结果按模型编号稳定输出。test_lod_error_select.py 的十五个用例当前无一通过，压距离一刀切、分辨率、视场角、视锥边缘、档位抖动、无过渡、强制档、零距离、远距兜底、性能预算、误差公式、同误差取面数、滞回、交叉权重和稳定输出。

## 运行方式
```bash
python -m pytest tests -q
```
