# GSB Bugfix Task
## 题面
客服坐席启用了可信设备，本意是少发几次短信，结果先被内部人钻了空子。员工把自己的设备登记成可信之后，把设备凭证复制给外包同学，外包在另一台机器上直接免验证登录；同一个凭证被两个城市同时使用，系统没有任何反应；设备列表只增不减，离职员工的设备还在；改密之后旧凭证仍然有效；设备名称允许任意文本，列表页被塞进脚本；登记接口没有二次验证，刚注册的账号也能直接加设备；可信期写的是三十天，实际永不过期；设备指纹只取了浏览器标识，换个浏览器就算新设备；撤销设备只删了列表项，凭证还能用；同一账号最多五台设备的限制没有生效；凭证轮换时旧的没有宽限，正在用的页面全部掉线；最后活跃时间从不更新；审计只记登记不记撤销。trusted_device_ledger.py 的 TrustedDeviceRegistry 要把设备生命周期管住：登记必须发生在一次强验证之后，凭证绑定用户、设备指纹和登记时间，库里只放摘要；每个账号的设备数量、单设备有效期、闲置期都可配置；凭证使用要刷新最后活跃时间，跨地域或指纹变化触发复验；改密、封号、撤销要立刻让对应凭证失效；轮换时旧凭证保留一个短宽限且只能用于只读请求；设备名称做长度和字符限制并在输出时转义；列表按登记时间稳定排序，导出视图不含凭证原文。test_trusted_device_ledger.py 的十五条断言现在全部失败，覆盖凭证复制、异地并发、只增不减、改密残留、名称注入、无强验证登记、永不过期、指纹过粗、撤销失效、数量上限、轮换宽限、活跃时间、审计撤销和导出脱敏。

## 运行方式
```bash
python -m pytest tests -q
```
