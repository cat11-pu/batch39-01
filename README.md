# GSB Bugfix Task
## 题面
语音聊天接入不同采样率的设备后，声音开始忽快忽慢。四十四点一千赫兹转四十八千赫兹时，代码直接按整数倍率算，实际比例不整，十分钟后累计漂移了半秒；缓冲区大小写死，采样率高的设备延迟翻倍；多声道下只处理了第一个声道，其余声道被复制；重采样后的总样本数算错，最后一段不是多出静音就是被截断；输入是浮点、输出是十六位整数时没有做限幅，响的地方爆音；分块处理时每块单独算相位，块与块之间出现咔哒声；采样率相同也走了一遍滤波，音质反而变差；零采样率和负采样率没有拒绝；声道数变化时混音矩阵缺失；滤波器长度按固定值取，低采样率下过渡带太宽。audio_resample_plan.py 的 AudioResamplePlan 要先产出重采样计划再执行：输入输出采样率用整数比表示，先求最大公约数得到最简比例；按比例和滤波器长度算出每块输入样本数、输出样本数和相位余量，块与块之间传递余量，保证总输出样本数等于理论值；相同采样率直接透传，不做滤波；多声道逐个处理，声道数变化时要求显式混音矩阵；浮点转整数前按目标位深限幅；滤波器长度按过渡带和采样率计算，给出延迟；零、负采样率和声道数为零拒绝；计划包含块数、每块样本数、总延迟和末尾补零数，执行结果与一次性处理在容差内一致。test_audio_resample_plan.py 的十五条检查现在全部失败，压不整比例、缓冲区、多声道、总样本数、限幅、分块相位、同率透传、零率、负率、混音矩阵、滤波器长度、漂移、末尾补零、计划字段和分块一致。

## 运行方式
```bash
python -m pytest tests -q
```
