# GSB Bugfix Task
## 题面
字幕组交来的文件一导入就出问题：两条时间重叠的字幕，后一条直接把前一条顶掉，观众只看到半句；相邻两条之间只隔四十毫秒，播放时闪一下；最短显示时间没有约束，一条“嗯”只闪了八十毫秒；每行字数没有上限，宽屏上字幕溢出画面；阅读速度按字符数算，中文和英文用了同一个阈值，英文长句根本读不完；时间戳有毫秒和帧号两种写法，转换时四舍五入方向不一致，越到片尾偏差越大；字幕条目顺序是乱的，合并时没有先排序；零时长和负时长条目被静默丢弃；带说话人标签的行被当成正文参与合并；两条样式不同的字幕重叠时被强行合并，颜色丢了；同一文件重复导入，字幕条数翻倍。subtitle_cue_merge.py 的 SubtitleCueMerge 要先规范化再合并：时间统一到毫秒，帧号按项目帧率换算并保留原始值；条目按开始时间、结束时间、原始序号稳定排序；重叠条目按样式和说话人分组，同组内合并为一条，不同组保留并标记冲突；合并后最短显示时间可配置，不足时向后延长但不侵入下一条；相邻间隔小于阈值的条目合并；每行最大字符数按语言区分，超长时在标点处换行；阅读速度按语言阈值校验，超限给出警告而不是丢弃；零时长、负时长、乱序、重复导入都要有明确处理；输出保留原始序号映射和全部警告。test_subtitle_cue_merge.py 的十五个用例眼下均未通过，压重叠、短间隔、最短时长、行宽、阅读速度、帧号换算、乱序、零时长、负时长、说话人、样式冲突、重复导入、稳定排序、警告和序号映射。

## 运行方式
```bash
python -m pytest tests -q
```
