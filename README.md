# GSB Bugfix Task
## 题面
射击手感调整之后，玩家反馈第一发不准、连射像放烟花。首发精度没有单独配置，第一发就吃了满散布；连射时散布按固定值跳变，没有平滑增长；停火后散布立刻归零，下一梭又从头开始；开镜倍率只改了视野，散布没有跟着缩小；移动和跳跃的惩罚叠乘，跑动射击几乎打不中；霰弹的弹丸分布用纯随机，弹着点扎堆；随机种子每发都重置，回放和训练场对不上；后坐力模式只做了向上，左右偏移完全随机；散布上限没有夹紧，连续射击后准星比屏幕还大；蹲伏和站立的恢复速率一样。projectile_spread_pattern.py 的 ProjectileSpreadPattern 要给出可复现的弹道：每个武器配置首发精度、每发增量、恢复速率、上限和开镜倍率；连射时散布按增量累积并夹到上限，停火后按恢复速率衰减，不瞬间归零；移动、跳跃、蹲伏各有独立系数，按乘算叠加但受总上限约束；霰弹弹丸按配置的角度分布和数量生成，使用调用方传入的种子，同一序列可复现；后坐力模式支持固定图案和镜像，水平偏移按图案取值；开镜和腰射使用不同上限；结果返回每发方向、当前散布和恢复剩余时间，重复输入一致。test_projectile_spread_pattern.py 的十五个断言全部报错，压首发精度、连射增长、停火恢复、开镜倍率、移动惩罚、跳跃、霰弹分布、种子复现、后坐力图案、上限夹紧、蹲伏、衰减、镜像、方向和剩余时间。

## 运行方式
```bash
python -m pytest tests -q
```
