# GSB Bugfix Task
## 题面
潜行游戏的手电筒光照一直在穿墙：角色贴着墙角站立时，光锥直接穿过两面墙的接缝；墙段只有一像素厚，射线从端点外侧擦过去，墙后整片被照亮；两面墙部分重叠时，端点没有去重，生成的多边形出现自交；光源在墙里时，可见区域应该是空的，代码却返回了整圆；光锥角度设成三百六十度时，起止射线重复，首尾顶点接不上；半径边缘的衰减和可见多边形分开算，边缘出现一圈硬边；地面上的箱子作为遮挡物时，底面和顶面被当成两个物体，光从中间漏过；光源移动一像素，顶点顺序整体翻转，阴影闪烁；地图有五千段墙，每帧全量射线排序卡到十毫秒；浮点误差让共线端点产生重复顶点。visibility_fan.py 的 VisibilityFan 要算出稳定的可见多边形：先把墙段端点按角度排序，角度相同的端点合并，墙段朝向统一；射线只向端点和端点两侧的微小偏移投射，求最近交点；光源落在墙内或墙段包围盒内时返回空区域；可见点按角度顺序连成扇形，首尾闭合，去掉重复和共线点；支持整圆和任意张角，张角边界单独补射线；半径裁剪在求交时完成，衰减系数单独输出；遮挡物按标识去重，同一物体的多个面合并；输出顶点顺序固定，光源微移不改变拓扑；五千段墙的单帧计算要能复用上一帧的排序结果。test_visibility_fan.py 的十五条断言现在全部失败，覆盖墙角接缝、薄墙、重叠墙、光源在墙内、整圆、硬边、箱子漏光、顶点翻转、大图性能、共线点、端点合并、张角边界、半径裁剪、遮挡去重和排序复用。

## 运行方式
```bash
python -m pytest tests -q
```
