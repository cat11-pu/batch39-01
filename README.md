# GSB Bugfix Task
## 题面
镜像构建流水线扫描基础镜像时，发现里面留着三把来路不明的登录公钥。审计脚本按空格切行，带空格的命令选项被切成两半；来源限制写成多个网段，脚本只取了第一个；限制终端、禁止转发这类无值选项被当成带值选项，后面的密钥类型整体错位；同一把密钥换了注释又出现一次，报告里算成两条；密钥主体不是合法编码，脚本抛异常后整份清单没扫完；公钥类型写成不认识的缩写仍然被记为有效；注释里带换行，写报告时多出一行；弱密钥长度没有单独标记；未知选项被静默忽略，审计结论失真。authorized_keys_fence.py 的 AuthorizedKeysFence 要把清单解析成审计条目：先按引号感知的规则切分选项，再区分带值和不带值两类；来源限制支持多个网段并逐项校验；命令选项还原引号和转义后整体保存；密钥类型只允许白名单，主体做编码和长度校验，失败时带行号继续扫描下一条；重复密钥按类型和主体指纹归并，保留首次出现的行号；注释去换行并限制长度；弱密钥、未知选项、空行分别计数；输出按行号稳定排序，包含选项、类型、指纹、长度和告警。test_authorized_keys_fence.py 的十五项检查现在全部报错，压命令空格、多网段、无值选项、重复密钥、非法编码、未知类型、注释换行、弱密钥、未知选项、行号、归并、计数、排序、指纹和继续扫描。

## 运行方式
```bash
python -m pytest tests -q
```
