# GSB Bugfix Task
## 题面
怪物 AI 的行为选择完全看运气：同一只怪在同样血量下，有时冲锋有时发呆。评分函数把距离、血量、怒气乘在一起，量纲不同，距离一项永远压过其他项；技能冷却中的行为仍然参与评分，只是执行时被拒绝，导致怪物站着不动；两个行为分数只差零点一时每帧来回切，动作起手被打断；低血量逃跑和狂暴的分数交叉点没有滞回，怪物在边界反复横跳；所有分数都是零时随机选，回放对不上；负权重把总分拉成负数，选择函数直接选了下标零；一个大招的分数算出来超过浮点上限，变成无穷；行为的前置条件失败时没有从候选里剔除，只是执行阶段报错；玩家进入范围的事件没有打断当前引导技能；行为表为空时抛异常。ai_utility_choice.py 的 AiUtilityChoice 要给出确定且可解释的选择：每个行为声明权重、评分曲线、冷却、前置条件和打断优先级；评分先按各自曲线归一化到零到一，再乘权重求和；冷却中或前置条件不满足的行为直接不进入候选；当前行为在滞回区间内保持，超出才切换；多个行为同分时按优先级、行为编号依次打破；全部不可用时返回空闲行为而不是抛异常；被更高优先级行为打断时记录原因；输入带随机种子，平局和抽样都确定；结果包含候选列表、每项得分和最终选择。test_ai_utility_choice.py 的十五个用例现在都没有通过，压量纲、冷却候选、频繁切换、滞回、全零、负权重、数值溢出、前置条件、事件打断、空表、归一化、同分、种子、候选输出和空闲兜底。

## 运行方式
```bash
python -m pytest tests -q
```
