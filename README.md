# GSB Bugfix Task
## 题面
战争迷雾在大地图上同时出现三种毛病：单位走过的地方过一会儿又黑了，已经探索过的区域没有记住；两个队友站在一起，视野没有合并，中间夹着一条黑缝；单位死亡后视野立刻消失，但按照设计，探索过的地形应该保留；迷雾边缘是硬邦邦的格子锯齿，美术要求做一圈半透明过渡；地图分块加载后，跨块的视野没有接上，区块边界出现一条竖线；负坐标区域根本没有生成迷雾数据，单位走到地图左上角就全亮；同屏两队人时，敌方单位的隐身状态被己方视野错误揭示；重新进入已探索区域时，迷雾没有从记忆状态恢复到可见状态；每帧对整张地图做一次可见性计算，十秒后卡成幻灯片；迷雾快照导出再导入后，探索状态和可见状态混在一起。fog_reveal_grid.py 的 FogRevealGrid 要按队伍维护三层状态：未探索、已探索但不可见、当前可见；可见性按单位视野半径和视线遮挡逐格计算，多个单位取并集，跨区块共享同一套坐标；单位死亡或离开后只把当前可见降为已探索，不清除记忆；边缘过渡按到可见格的距离生成权重，供渲染层做渐变；负坐标和超大坐标用统一的分块映射；敌方隐身单位只有进入当前可见层才揭示；重新进入区域时从记忆层恢复可见层；每帧只重算视野单位周围的分块，其余复用缓存；导出快照按队伍、分块、三层状态稳定排序，导入后行为一致。test_fog_reveal_grid.py 里十五个用例全部报错，压记忆丢失、队友合并、死亡保留、边缘过渡、跨块接缝、负坐标、隐身、重入恢复、全图重算、快照往返、三层状态、视线遮挡、分块映射、缓存复用和稳定排序。

## 运行方式
```bash
python -m pytest tests -q
```
