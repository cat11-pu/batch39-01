# GSB Bugfix Task
## 题面
音频编辑器的波形图一放大就变成方块，缩小时又看不出瞬态。现在的峰值索引只有一档，按固定一千个样本一桶，缩放后只能重复采样；桶里只存了最大值，负半周的峰值丢了，波形上下不对称；静音段没有标记，界面画出一条细线，用户以为文件损坏；立体声两个声道混成一个桶，左右相位相反的段落显示成全静音；文件是二十四位打包格式，读取时按十六位解析，峰值全错；增量导入时只算了新增部分，桶边界没有对齐，接缝处出现尖刺；文件末尾不足一桶的样本被丢弃；空文件和单样本文件直接除零；多个缩放级别各自缓存，内存涨到几百兆；同一文件两次生成的索引校验和不同。waveform_peak_index.py 的 WaveformPeakIndex 要建多分辨率峰值索引：按基础桶大小生成最细一层，每个桶记录最小值和最大值，上一层由下一层两两合并；静音判定用绝对值阈值，单独标记；立体声默认分声道存，需要混音时按平均值并标记相位抵消；支持八位、十六位、二十四位打包和浮点输入，统一归一到浮点再算；增量更新按桶边界对齐，只重算受影响的桶和上层；末尾不足一桶的样本单独成桶并标记；空文件返回空索引而不是异常，单样本正常生成；每层缓存有内存上限，超出按缩放级别淘汰；索引带源文件摘要和版本，重复生成校验和一致。test_waveform_peak_index.py 的十五个用例当前全部失败，压单档、负峰值、静音、立体声、二十四位、增量对齐、末尾桶、空文件、单样本、内存上限、多级合并、摘要、校验和、相位抵消和缩放缓存。

## 运行方式

```bash
python -m pytest tests -q
```
