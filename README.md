# GSB Bugfix Task
## 题面
美术从三家外包收来的模型一开背面剔除就出现黑洞，法线看着也对，实际是三角形的绕序反了。有的模型里混着零面积三角形，导入器直接除零；重复顶点没有合并，接缝处出现双份法线；索引数组里有越界值，渲染时读到别的网格；同一个顶点在 UV 缝两侧位置相同但纹理坐标不同，按位置合并会把缝焊死；材质分组把三角形切得七零八落，修复后分组顺序变了；空网格和只有一个点的网格让统计函数抛异常；非流形边上的绕序无法判断，代码随机选了一个方向；包围盒因为几个离群顶点被撑得极大；法线重算后和原始法线方向相反；索引类型是十六位时，顶点数超过六万五千没有报错而是回绕。mesh_winding_repair.py 的 MeshWindingRepair 要在导入后做一次可复核的修复：先剔除越界索引和零面积三角形，再按位置、法线、纹理坐标三元组焊接顶点，UV 缝两侧不合并；用邻接关系给每个连通分量投票决定整体朝向，投票相同按包围盒最小的面确定；非流形边单独列出，不强行翻转；重算法线时保持与原始法线同向，无法判断的标记为待人工确认；材质分组和三角形顺序保持稳定，修复只改索引不改顶点顺序；输出修复前后的统计、被剔除的三角形编号和仍存疑的边；整个过程不修改输入数组，结果可重复。test_mesh_winding_repair.py 目前十五项检查均为失败，压绕序翻转、零面积、重复顶点、越界索引、UV 缝、材质分组、空网格、非流形、离群点、法线同向、索引回绕、统计、输入不变、可重复和存疑清单。

