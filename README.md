# GSB Bugfix Task
## 题面
运营后台的短信模板支持美元花括号表达式，上周有实习生写了访问对象内部类型的表达式，把内部结构打到了预览页；又有人通过内置模块读到了环境变量。现在的求值就是把表达式丢给 Python 的 eval，等于把后台开给了所有运营。需要换成 template_sandbox_eval.py 里的 TemplateSandbox：只认变量、常量、算术、比较、布尔和一小撮白名单过滤器，属性访问只允许白名单字段，下划线开头的名字一律拒绝，函数调用只允许过滤器形式；表达式长度、嵌套深度、循环次数都要有上限；未定义变量按空串处理还是报错要由开关决定，默认报错并指出变量名；数字格式化要固定小数位，不能出现科学计数法；日期过滤器只接受 ISO 字符串；输出默认做 HTML 转义，raw 过滤器要显式开启；嵌套模板只允许一层。test_template_sandbox_eval.py 的十五个用例当前全红，分别压双下划线、环境变量、白名单字段、过滤器、长度、深度、循环、未定义变量、数字格式、日期、转义、raw 开关、嵌套、语法错误定位和重复求值一致性。

## 运行方式
```bash
python -m pytest tests -q
```
