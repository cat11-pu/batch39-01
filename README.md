# GSB Bugfix Task
## 题面
客服后台改成单点登录之后，会话这块的投诉就没停过。管理员把自己从只读提到超管，令牌没换，之前被降权时打开的页面还能接着操作；退出登录只清了浏览器的 cookie，服务端记录还在，拿旧值重放照样能进；一个人开五个标签页，轮换时另外四个立刻掉线，用户骂到产品那边；轮换后购物车草稿丢了；并发请求正好卡在轮换瞬间，有的走新令牌有的走旧令牌，同一个操作被记了两次；空闲十五分钟没退出，但绝对有效期到了也没人踢；设备换了一台，旧设备没有被清；令牌放在地址栏里被代理日志记了下来；审计只记登录成功，不记旧令牌重放。session_rotate_chain.py 的 SessionRotateChain 要把轮换做成一条有状态的链：登录成功、权限变更、改密、切换租户这四个时点必须换新令牌，旧令牌立刻进入只读的短暂宽限，宽限期内只允许已经发出的在途请求完成，超过宽限或用于写操作就拒绝；同一浏览器的多个标签页共享链编号，轮换后旧标签页拿到的是迁移提示而不是直接 401；草稿、未提交表单这类临时数据要跟着链走；空闲超时和绝对超时分别计算，任一触发都终止整条链；登出、封禁、改密要能按用户清掉全部链；每条链绑定设备指纹，换设备只允许重新认证，不允许迁移；被拒绝的旧令牌重放要单独计数并进审计。test_session_rotate_chain.py 的十五条断言现在全部失败，覆盖权限变更、登出残留、多标签、草稿迁移、并发宽限、写操作拦截、空闲超时、绝对超时、换设备、地址栏泄露、重放审计、按用户清链、链编号共享、宽限过期和快照隔离。

## 运行方式
```bash
python -m pytest tests -q
```
