# GSB Bugfix Task
## 题面
等距视角的塔防地图上，角色走到建筑后面时整个人被盖住，走到侧面又跑到建筑前面，美术说像在纸片里穿模。现在的排序键只取了屏幕纵坐标，占地两格宽三格高的建筑和一格的小怪共用一个值；角色跨格移动时位置是小数，排序键没有跟着插值，走到一半会突然跳层；高塔的贴图很高，但锚点在脚底，按脚底排序后塔身遮不住后面的地面单位；阴影和本体用了同一个层，阴影有时盖住角色；桥面分上下两层，同一格上的单位没有按层号区分；坐标是负数时排序方向反了；相同排序键的两个单位顺序随插入顺序变化，回放每次不一样；地图放大到两千格后排序耗时明显；地面装饰和可交互物混在一起；单位死亡后残影还留在排序表里。iso_depth_sort.py 的 IsoDepthSort 要给出稳定的深度序列：每个对象带占地宽高、脚底锚点、层号和类型，深度键先按层号，再按脚底所在的行加列，最后按对象编号打破平局；跨格移动时按连续坐标插值出亚格深度，不能跳层；高体积对象用脚底参与排序但覆盖范围要单独记录，供遮挡查询；阴影固定排在本体前一层；桥和地面通过层号分开，同层才比较行列；负数坐标用同一套整数映射；装饰物可以配置为不参与遮挡；排序结果与插入顺序无关，重复调用一致；对象移除后不残留。test_iso_depth_sort.py 的十五个用例现在全部失败，覆盖占地、跨格插值、高塔、阴影、桥层、负坐标、平局、插入顺序、重复调用、移除、装饰物、层号优先、遮挡查询、大图性能和快照一致。

## 运行方式
```bash
python -m pytest tests -q
```
