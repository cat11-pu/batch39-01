# GSB Bugfix Task
## 题面
CI 的测试矩阵清单从表格迁到 YAML 之后，调度服务每天都要人工捞一次坏任务。外包交来的清单里，锚点套了四层，展开后节点数翻了上千倍；别名指回自己的父节点，转换器递归到栈溢出；自定义标签写着执行命令，加载器照单全收；两个文档之间没有分隔符，第二份被当成第一份的延续；时间戳字段被自动转成日期对象，矩阵键名对不上；空值和缺失字段在生成的 JSON 里都变成 null，下游分不清；同名键出现两次，后者悄悄覆盖前者；行尾回车被算进标量，任务名多出不可见字符。yaml_tag_fence.py 的 YamlTagFence 要改造成事件流式的清单转换器：按事件逐个产出清单节点，不把整份文档一次性建成对象；锚点和别名只允许向后引用，展开后的节点总数、嵌套层数、单标量长度都有上限，检测到环立即报错并给出锚点名；标签白名单只放行字符串、整数、浮点、布尔、空、序列和映射，其余按行列拒绝；时间戳、二进制和带引号的数字一律保持原始文本；多文档要么全部转换成功，要么整体失败，不能输出半份；空值与缺失键在结果里用不同标记；重复键在同一个映射内拒绝；输出保持键的原始顺序，注释丢弃。test_yaml_tag_fence.py 的十五个断言现在全部失败，压锚点环、别名膨胀、危险标签、多文档、时间戳、二进制、空值缺失、重复键、深度、标量长度、行列定位、键顺序、事件流内存、注释和重复转换一致。

## 运行方式
```bash
python -m pytest tests -q
```
