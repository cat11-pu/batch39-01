# GSB Bugfix Task
## 题面
技能特效在低端机上爆炸式掉帧，粒子数量明明没变。排查发现曲线是在每帧对每个粒子重新求值，关键帧多了之后开销全压在渲染线程；关键帧时间没有排序，后插入的关键帧被直接忽略；循环曲线在结尾到开头之间没有过渡，粒子颜色闪一下；曲线求值遇到重复时间点时除了零，整帧粒子消失；缓动函数只支持线性，策划配的缓入缓出全被当成线性；低画质档要求粒子数减半，但曲线采样密度没跟着降，远看还是一样的开销；预 warm 时粒子从零开始，技能第一帧明显空；爆发模式下同一帧生成上千粒子，随机种子没固定，回放不一致；颜色渐变的透明度没有做预乘，叠在亮背景上发灰；曲线值超出上下限没有夹紧；时间倒退时没有回到正确的循环段。particle_curve_bake.py 的 ParticleCurveBake 要把曲线预先烘焙成采样表：关键帧按时间稳定排序，重复时间以后出现的为准并去重；支持线性、缓入、缓出和自定义控制点四类插值；循环模式在首尾之间做连续过渡，单次模式在两端夹紧；采样表按目标帧率和画质档生成，低画质档降低采样密度但保留首尾和极值；预 warm 从负时间开始求值；爆发使用调用方传入的种子，同一输入同一序列；颜色通道先预乘透明度再输出；值超出范围夹到端点；时间倒退按循环长度取模回绕；烘焙结果只读，重复烘焙同输入得到同表。test_particle_curve_bake.py 的十五个用例现在全部失败，覆盖乱序关键帧、重复时间、循环过渡、零除、四类缓动、低画质采样、预 warm、爆发种子、颜色预乘、范围夹紧、时间倒退、稳定排序、极值保留、只读结果和重复烘焙一致。

```bash
python -m pytest tests -q
```
