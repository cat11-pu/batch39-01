# GSB Bugfix Task
## 题面
即时战略里的单位一遇到会移动的障碍就开始原地打转。每帧都从头算一遍完整路径，几十个单位同屏时寻路预算直接爆掉；障碍挪走之后单位还沿着旧路径撞墙；目标点在障碍里时返回空路径，单位站着不动也不报错；路径平滑只做了直线检测，拐角处的单位半径没有考虑，贴着墙角走会卡住；斜向移动的代价和直线一样，单位全走对角线；两个单位抢同一个格子，先到的被后到的挤开；寻路失败后没有降级方案，单位直接罚站；路径重算时把已经走完的前半段也丢了，单位往回走；目标移动后没有增量更新，直到下一帧才反应；开放格子和封闭格子的判定用了不同的坐标约定。path_replan_window.py 的 PathReplanWindow 要支持增量重规划：保留当前路径已经走完的前缀，只对剩余部分重算；每帧有固定的重算预算，按单位优先级分配，超预算的排队到下一帧；障碍变化只影响受影响区域，未受影响的路径段直接复用；目标在障碍内时返回最近可达点并标记；平滑时按单位半径做膨胀检测，斜向代价按根号二计算，禁止穿角；多个单位的目标格冲突按编号排序分配；完全无路时返回部分路径和失败原因，不抛异常；目标移动超过阈值才触发重算；坐标约定统一为格子左下角，开放与封闭判定共用一套函数。test_path_replan_window.py 里十五个用例当前全部失败，压每帧全算、障碍移动、目标在障碍、半径卡墙、斜向代价、抢格、无降级、前缀丢失、目标移动、坐标约定、预算分配、区域复用、最近可达、穿角和部分路径。

## 运行方式
```bash
python -m pytest tests -q
```
