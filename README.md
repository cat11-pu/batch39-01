# GSB Bugfix Task
## 题面
打击感系统加上顿帧之后，Boss 战偶尔会整场卡住。每次命中都往队列里塞一个冻结请求，同时命中五段伤害就叠了五倍时长；冻结没有优先级，轻击把重击的顿帧覆盖掉；最大时长没有上限，连续命中让画面停了两秒；时间缩放直接写成零，UI 动画和音频也跟着停；暂停菜单打开时顿帧计时还在走；帧间隔很大时一次性扣完，恢复时跳帧；过量伤害和普通命中用了同一档；Boss 的免疫标记没有生效；冲刺无敌帧期间仍然触发顿帧；队列里的请求没有过期时间，场景切换后还在。hitstop_queue.py 的 HitstopQueue 要按优先级合并冻结请求：每个请求带强度、优先级、持续时间和来源；同一帧多个请求按优先级取最高，强度相加但总时长夹到上限；低优先级请求不能覆盖高优先级；冻结只作用于战斗逻辑时钟，UI、音频和相机保持正常；暂停时冻结计时暂停；帧间隔按子步累计，恢复时平滑过渡；过量伤害、免疫目标和无敌帧按规则忽略；请求带过期时刻，场景切换或超时自动清理；结果返回当前时间缩放、剩余冻结和生效来源。test_hitstop_queue.py 的十五个用例当前全部失败，压叠加、优先级、时长上限、时间缩放、UI 隔离、暂停、大帧间隔、过量伤害、免疫、无敌帧、过期清理、同帧合并、来源输出、平滑恢复和场景切换。

## 运行方式
```bash
python -m pytest tests -q
```
