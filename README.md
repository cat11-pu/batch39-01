# GSB Bugfix Task
## 题面
容器安全基线要求收窄进程能力，扫描器却把配置读错了。能力名大小写混用，代码只认小写，未知项被静默跳过；数字写法和名字写法混在一行，重复项没有去重；全集关键字和单项同时出现，后者被忽略；文件能力写成设置位的形式，解析器只取了名字，设置位全丢；可继承集和受限集搞反，执行后权限反而变大；环境能力没有检查可继承和许可两个前置集合；受限集删除之后又通过文件能力加回来；空集合和缺省集合被当成同一种；超过六十四位的编号直接截断；未知能力没有报错。capability_set_parse.py 的 CapabilitySetParse 要解析并计算能力集：支持名字、数字、全集和空集四种写法，名字统一小写并拒绝未知项；重复项去重，全集与单项冲突时给出明确语义；设置位支持许可、有效、可继承三类组合；计算执行后的能力时按许可、可继承、受限和环境四个集合的规则推演，受限集只能缩小；环境能力必须同时出现在可继承和许可集合里；文件能力的设置位与进程集合分开保存；编号必须在零到六十三之间；空集与缺省要能区分；结果返回四个集合、执行后集合和告警。test_capability_set_parse.py 的十五个用例眼下全部失败，压大小写、数字混写、重复项、全集冲突、设置位、集合搞反、环境前置、受限回加、空集缺省、超界编号、未知项、执行推演、文件能力、告警和快照。

## 运行方式
```bash
python -m pytest tests -q
```
