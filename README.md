# GSB Bugfix Task
## 题面
过场动画改成离线烘焙阴影后，美术发现同一段镜头里地面阴影一会儿清楚一会儿糊。烘焙器按镜头序号平均分配层级，近景和远景拿到一样的贴图尺寸；每层的深度区间直接取整段动画的最近最远值，中间大段空深度也被算进去；每层贴图各自独立，图集里留下大量空白；相邻两层没有重叠，接缝处阴影断开；镜头切换时层级编号重排，已经烘好的瓦片对不上；空层也占一张图；灯朝向和镜头朝向接近平行时，投影盒算得极小，阴影被裁掉；总显存预算没有上限，四个镜头一起烘就爆。shadow_cascade_fit.py 的 ShadowAtlasPlanner 要为离线烘焙产出分层计划：按镜头里可见物体的深度分布切分层级，支持按覆盖率分配分辨率；每层深度只包住该层可见几何，留出配置的重叠带；每层瓦片写入共享图集，记录矩形和纹素密度；相邻层的重叠区域用于接缝融合；镜头切换时按镜头标识稳定生成层级编号，不因顺序变化重排；空层不分配瓦片；灯朝向与镜头朝向夹角过小时给出退化标记；总瓦片数、单层分辨率和总显存有上限；输出每层的深度区间、图集矩形、纹素密度和告警。test_shadow_cascade_fit.py 的十五个用例现在全部失败，压平均分配、深度区间、图集空白、接缝、编号重排、空层、平行光、显存预算、覆盖率、重叠带、纹素密度、退化标记、瓦片矩形、上限和稳定输出。

## 运行方式
```bash
python -m pytest tests -q
```
