# GSB Bugfix Task
## 题面
资源打包工具开始读 TOML 清单之后，两个不同角色的贴图被打进同一个包。清单里先声明了数组表，后面又用点号键往同一路径塞字段，解析器把两段合并成一个表；同一个表被声明两次，第二次直接覆盖第一次，旧字段消失；内联表和外层表指向同一键，谁生效取决于书写顺序；十六进制和八进制整数被当成十进制，资源编号全错；日期时间被转成对象，包名比较失败；带引号的键里含点号，代码按点号切开，键被拆成三层；多行字符串的续行反斜杠没有处理，路径里混进空白；数组表里混入非表元素，遍历时类型错乱。toml_key_fence.py 的 TomlKeyFence 要把清单解析成规范化的资源图：数组表按出现顺序追加，点号键和显式表指向同一路径时拒绝而不是合并；表重复声明报错并指出行列；内联表按值处理，不与外层表合并；整数支持十、十六、八、二进制并保留原始进制标记；日期时间保存为原文字符串；带引号的键整体作为一个键，不按点号切分；多行字符串按规范处理续行和转义；数组表元素类型必须一致；嵌套深度、节点数、单标量长度有上限；输出按资源编号稳定排序。test_toml_key_fence.py 的十五条检查眼下均未通过，压数组表合并、表重复、点号冲突、内联表、进制、日期时间、引号键、多行续行、元素类型、深度、节点数、标量长度、行列、排序和重复解析。

## 运行方式
```bash
python -m pytest tests -q
```
