# GSB Bugfix Task
## 题面
像素小镇的昼夜色调靠同一张索引图切换色表，黄昏时屋顶和窗户串了色。索引零既表示透明又表示最深的黑，代码把整片天空染成了黑色；色表长度比索引范围短，越界索引读到了相邻图层的颜色；白天到夜晚的过渡直接替换整张色表，中间没有混合，画面一跳；半透明边缘按阿尔法混合后又做了一次色调叠加，边缘发灰；图集子区域的偏移没有跟着换色表走，旁边的图标被一起改色；缓存只按时间段编号命中，换了色表版本仍然拿旧结果；连续切换十次昼夜后颜色越来越偏，没有还原到原始索引图；灰度图没有色表，代码直接抛异常；索引超过二百五十五时静默回绕。sprite_palette_swap.py 的 SpritePaletteSwap 要按索引语义换色：透明索引原样保留，其余索引查色表；色表长度必须覆盖最大索引，越界时报坐标；昼夜过渡支持替换和按权重混合两种模式，混合按阿尔法加权；图集子区域按矩形裁剪，换色不越界；缓存键包含图集版本、色表版本和过渡权重；提供还原原始索引图的操作；灰度图使用内置色表；索引超限报错；输出换色后的图像、命中缓存标记和告警。test_sprite_palette_swap.py 的十五条断言当前全部失败，压透明索引、色表越界、过渡混合、阿尔法、图集偏移、缓存键、还原、灰度、索引超限、替换模式、权重、坐标报错、告警、版本和重复换色。

## 运行方式
```bash
python -m pytest tests -q
```
