# GSB Bugfix Task
## 题面
大世界的草地一加载就出现两种毛病：区块接缝处的草密了一倍，远处又整片空掉。密度图按区块各自采样，边界像素被两个区块各算一次；坡度过滤只看高度差，陡坡上的草仍然长出来；高度范围用了世界坐标，不同海拔的区块表现不一致；最小间距检查只在区块内做，跨区块的草叠在一起；LOD 降密度时直接隔点取，草的分布出现条纹；随机种子按区块编号生成，相邻区块的图案重复；道具和建筑占地区域没有排除，草从箱子里穿出来；单区块实例数没有上限，密集区直接爆内存；风相位按实例编号算，同一片草相位跳变；相机裁剪包围盒没有算草的摆动范围。grass_scatter_plan.py 的 GrassScatterPlan 要生成确定且无缝的分布：密度图按世界坐标采样，区块边界用同一套半开区间规则，避免重复和空洞；坡度和高度过滤用世界单位，阈值可配置；最小间距用网格加速，跨区块共享邻域；LOD 按密度比例做确定性抽样，不用隔点；随机种子由世界坐标和全局种子共同决定，相邻区块不重复；道具占地按包围盒排除；单区块和总实例数都有上限，超出按优先级裁剪；风相位由位置哈希得到；裁剪包围盒包含摆动幅度；输出每个实例的位置、朝向、缩放和区块编号。test_grass_scatter_plan.py 的十五条断言当前全部失败，压接缝双倍、坡度、高度、跨区间距、LOD 条纹、种子重复、道具避让、实例上限、风相位、裁剪包围、半开区间、网格加速、确定性、输出字段和内存上限。

## 运行方式
```bash
python -m pytest tests -q
```
