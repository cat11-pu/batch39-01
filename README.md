# GSB Bugfix Task
## 题面
招聘系统开放批量上传简历后，同一份文件被记到了三个候选人名下。表单里多个文件字段重名，前端按顺序取，后端按字典取，最后一个覆盖了前面；中文文件名经过一次编码再解码，扩展名变成乱码；文件名字段里带路径分隔符，落盘时跑出了候选人目录；整批请求没有总大小上限，一个人传了三百份简历把内存打满；单个文件超限时只截断不报错，简历后半段丢失；分隔边界外面多了一对引号，解析器把整段当成一个字段；某个分段的头部折行，后面的内容被算进文件名；请求缺少结束边界，接口仍然返回成功；字段顺序在结果里被重排，候选人对应关系错位。form_segment_fence.py 的 FormSegmentFence 要按上传清单逐段校验：字段名重复直接拒绝并指出重复项；文件名只保留最后一段，任何路径分隔符和控制字符都拒绝；整个请求、单个分段、头部行数、分段数量都有上限；边界支持带引号和多余空白；头部的折行先展开再判断，裸换行视为注入；缺少结束边界按残缺请求处理；每段计算内容摘要，清单按原始顺序返回字段名、文件名、大小和摘要；空文件名保留为空串，非法编码拒绝；快照与内部状态隔离。test_form_segment_fence.py 的十五个用例当前全部失败，压重名、中文文件名、路径、总大小、单段超限、引号边界、头部折行、缺尾、顺序、摘要、空文件名、非法编码、头部行数、分段数量和快照隔离。

## 运行方式
```bash
python -m pytest tests -q
```
