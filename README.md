# GSB Bugfix Task
## 题面
审计日志查询开放给租户管理员之后，越权和泄露一起来。一个租户的管理员把查询条件里的租户编号改成隔壁的，能看到别家的登录记录；普通坐席能查到超管的操作，角色层级没有参与过滤；导出接口没有单独限权，点一下就把全量记录拉走；时间范围可以传十年，查询直接把数据库拖垮；分页游标是明文的偏移量，改一个数字就能翻到别的租户；返回结果里的来源地址和邮箱没有脱敏，坐席能拿到完整值；已删除的记录还能被查出来；排序字段由前端传，传个不存在的字段就报内部错误；总数接口没有按权限过滤，能从数字推断别家有多少条；跨租户的记录编号没有被拒绝；查询关键字直接拼进条件，带引号的输入能改变语义；单页条数没有上限；导出文件没有水印和操作人；快照里的字段顺序不稳定。audit_query_scope.py 的 AuditQueryScope 要先把调用者的可见范围算出来，再做查询：租户边界由服务端会话决定，请求里的租户编号只能用于校验不能用于扩大范围；角色层级决定能看哪些操作者的事件；来源地址按网段掩码、邮箱按局部打码，敏感字段默认不返回；时间范围上限三十一天，超出要分段；游标带签名，包含查询条件摘要，篡改即拒绝；单页条数、导出条数、并发导出都要有上限；已删除记录默认不可见；排序字段走白名单；总数按同一范围计算；导出附操作人和时间水印。test_audit_query_scope.py 的十五个用例现在全部失败，覆盖跨租户、角色层级、导出越权、时间上限、游标篡改、字段脱敏、删除记录、排序注入、总数泄露、跨租户编号、关键字注入、单页上限、导出上限、水印和稳定快照。

## 运行方式
```bash
python -m pytest tests -q
```
