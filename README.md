# GSB Bugfix Task
## 题面
格斗游戏要把角色剪影导出成碰撞轮廓，程序生成的轮廓一上线就出现漏判：斜向相邻的像素被当成断开，贴身攻击从缝里穿过去；带半透明边缘的图按固定阈值取，轮廓一会儿胖一会儿瘦；中间挖空的披风只描了外圈，内圈没有封闭；轮廓点没有去重，相邻三点共线也保留，顶点数爆到上限；凹进去的地方外扩后自交，碰撞体出现负面积；图集里只取了一小块，采样越界把旁边角色的轮廓也带进来；剪影缩放后轮廓跟着缩放，物理尺寸和画面不一致；两个不相连的部件没有分组，碰撞查询把它们连成一片。sprite_outline_mesh.py 的 SpriteOutlineMesh 要从透明通道导出可用的轮廓网格：先按可配置阈值得到实心区域，八邻域判断连通并单独标记斜向连接；轮廓追踪按外环顺时针、内环逆时针，支持多个部件和孔洞；对轮廓做容差简化，合并共线点和距离过近的点；外扩前检查自交，自交处切成多段而不是生成负面积；图集采样限制在子区域内；输出按源像素单位记录，缩放到物理尺寸由调用方单独换算；顶点数、部件数和孔洞数有上限；结果与遍历起点无关。test_sprite_outline_mesh.py 的十五个用例全部失败，压斜向连通、半透明阈值、孔洞、共线点、顶点上限、外扩自交、图集越界、缩放一致、部件分组、遍历起点、容差简化、内环方向、负面积、上限和结果稳定。

## 运行方式
```bash
python -m pytest tests -q
```
