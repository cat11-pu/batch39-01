# GSB Bugfix Task
## 题面
射击项目换了新的命中反馈之后，镜头抖动被玩家吐槽像筛糠。现在的实现是每次开火直接给相机加一个随机偏移，多把武器同时开火就叠成几十像素，画面直接飞出安全区；抖动没有衰减，停火之后镜头还在抖；帧率从一百二掉到三十时，抖动幅度跟着变小，手感完全不一致；同一帧里加了三次震感，随机数各算各的，回放对不上；暂停菜单打开后镜头还在动；只抖了横向，纵向和旋转完全没有；开镜状态下抖动没有减半，瞄准点乱飘；屏幕边缘的 UI 也跟着抖；持续时间参数被忽略，大震和小震一样长；一次大爆炸叠加一次步枪，第二次把第一次的强度覆盖掉。camera_shake_falloff.py 的 CameraShakeFalloff 要把震感做成创伤模型：每个来源带强度、频率、持续时间和轴向权重，多个来源按平方和叠加后夹到上限；创伤按每秒固定速率衰减，衰减与帧率无关，帧间隔过大时按子步拆分；偏移用确定性噪声按时间采样，同一随机种子和同一时间序列得到同一结果；横向、纵向和旋转各自独立，开镜时按倍率缩小，UI 层不参与；暂停时时间冻结，恢复后从原创伤继续；强度为零、负数和超大值都要有明确处理；输出当前偏移、旋转和剩余创伤，供相机和测试复核。test_camera_shake_falloff.py 里十五个场景都没有通过，分别压多来源叠加、衰减、低帧率、随机确定、暂停、三轴、开镜、UI 排除、持续时间、覆盖、零强度、负值、子步拆分、种子一致和输出快照。

## 运行方式
```bash
python -m pytest tests -q
```
