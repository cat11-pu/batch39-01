# GSB Bugfix Task
## 题面
矢量图导出到低端设备后，圆弧变成了多边形，曲率大的地方还能看到明显的折角。现在的展平按固定段数切分，短曲线切得太密，长曲线又不够；容差参数写的是像素，但计算时用的是控制点距离，单位对不上；三次曲线里有尖点，固定步长直接跨过去，尖角被抹圆；控制点重合时除零；曲线自交时生成的折线没有去重，填充出现重叠边；闭合路径的终点和起点差了一个极小值，闭合判断失败；容差设成零时进入无限细分；参数映射只保留了端点，中间点的原始参数丢失；一条路径里混着直线段和曲线段，直线段也被细分；最大递归深度没有上限，恶意输入把栈打爆。bezier_flatten_tolerance.py 的 BezierFlattenTolerance 要按屏幕空间误差自适应展平：输入控制点、容差和变换矩阵，先把控制点变换到屏幕空间，再用平坦度指标决定是否继续细分；平坦度小于容差时输出线段，否则二分，尖点和拐点单独识别并保留；控制点重合、零长度和共线退化要有稳定输出；自交产生的重复点按容差合并；闭合路径首尾在容差内视为同一点；容差为零或负数拒绝，最大深度可配置；输出折线点、对应原始参数和每段的误差估计；同一输入重复调用结果一致，不修改输入。test_bezier_flatten_tolerance.py 里十五条检查全数报错，压固定段数、单位错误、尖点、控制点重合、自交、闭合、零容差、参数映射、混合路径、递归上限、屏幕变换、平坦度、重复点、误差估计和结果一致。

## 运行方式
```bash
python -m pytest tests -q
```
