# GSB Bugfix Task
## 题面
高尔夫回放里的挥杆轨迹带一到慢动作就断成几截。采样按固定帧号取，挥杆最快的那几帧点距太大，轨迹带出现折角；杆头速度变化时宽度按时间插值，收杆末端突然变粗；轨迹绕一圈回到起点时首尾没有闭合，接缝处纹理错位；急转弯用平均法线，外侧顶点翻到内侧，面片自交；相邻采样点距离过近仍然生成四边形，退化三角形一堆；一局下来点数没有上限，内存一直涨；回放跳到下一杆时轨迹横穿整张地图；慢动作降采样后颜色渐变断层；起点和终点没有端帽，看起来像被切断。ribbon_trail_mesh.py 的 RibbonTrailMesh 要按弧长和时间双条件采样：点距或时间超过阈值才新增，拐角按切线夹角判断，超过上限时断开；宽度和颜色沿弧长插值，支持收杆渐细和首尾端帽；闭合轨迹首尾切线对齐，纹理坐标连续；自交检测在生成前完成，冲突段切成多段；退化段和重复点跳过；最大点数、总弧长和回放时长有上限，超出淘汰最旧段；瞬移超过阈值时断开；慢动作降采样保留端点和极值；输出顶点、索引、段编号和包围盒。test_ribbon_trail_mesh.py 的十五个用例眼下均未通过，压快速挥杆、宽度收杆、闭合接缝、急转弯自交、退化面片、点数上限、回放跳转、颜色断层、端帽、弧长采样、降采样、瞬移、包围盒、段编号和结果一致。

