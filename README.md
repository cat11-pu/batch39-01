# GSB Bugfix Task
## 题面
主机防火墙规则从手工脚本迁到统一评估器后，几条本该被挡住的流量被放行了。规则表按顺序匹配，但用户自定义链返回之后没有回到调用点，直接落到默认策略；跳转链形成环，评估器递归到栈溢出；拒绝规则写在允许规则后面，评估器却先看了允许；源地址网段写成带主机位的格式，比较时没有归一；端口范围的上界小于下界，规则被静默跳过；协议名大小写不同被当成未知协议，规则失效；连接状态匹配把新连接当成已建立；接口名用了通配后缀，匹配范围被放大；规则计数器在拒绝时没有累加；默认策略缺失时按允许处理。netfilter_rule_eval.py 的 NetfilterRuleEval 要按链和顺序求值：每条规则带匹配条件和目标，目标支持接受、丢弃、拒绝、返回和跳转；跳转进入用户链，返回后继续调用点的下一条规则，跳转深度和环要有上限；匹配条件覆盖源目的网段、端口区间、协议、连接状态和接口名，网段先归一再比较，端口区间校验上下界，协议和接口名按规范大小写；规则按声明顺序求值，第一条完全匹配的规则生效；默认策略必须显式给出；计数按规则累加，拒绝也要计数；结果返回命中规则、经过的链和最终动作。test_netfilter_rule_eval.py 的十五个用例现在全部失败，压返回调用点、跳转环、顺序、主机位、端口区间、协议大小写、连接状态、接口通配、拒绝计数、默认策略、深度、网段归一、链路径、最终动作和快照。

## 运行方式
```bash
python -m pytest tests -q
```
