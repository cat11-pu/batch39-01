# GSB Bugfix Task
## 题面
面部表情系统一加组合表情就爆模，嘴角和眼皮翻到脑袋后面。多个形变目标按权重直接相加，权重和超过一也没有归一；负权重被夹到零，皱眉效果全丢；稀疏增量只给了部分顶点，代码按缺省零处理，基础网格被拉平；法线和切线没有跟着形变重算，光照方向全反；目标之间的顶点索引映射不一致，同一个顶点被加到别的部位；权重精度用半精度存储，微小表情直接归零；形变后的顶点超出包围盒，裁剪把脸切掉；切换目标时旧权重没有清零，表情叠加；超过硬件预算的目标数量没有分批；同一组权重重复计算结果不一致。blend_shape_morph.py 的 BlendShapeMorph 要按目标逐层计算：每个目标带稀疏顶点索引、位置增量、法线和切线增量，未给出的顶点保持基础值；权重先按配置归一，允许负权重和超过一的组合，但最终位置要夹到包围盒；法线和切线按同一权重线性组合后重新归一，退化时回退基础值；目标按声明顺序应用，支持加性和相对两种模式；索引映射在加载时校验，越界和重复索引报错；权重用双精度累计，输出前再量化；形变后更新包围盒并用于裁剪；目标数量超过预算时分批并保持结果一致；提供重置到基础网格的操作。test_blend_shape_morph.py 的十五个用例全部失败，压权重归一、负权重、稀疏增量、法线重算、索引映射、精度、包围盒、权重清零、预算分批、重复一致、加性模式、相对模式、切线、重置和越界索引。
