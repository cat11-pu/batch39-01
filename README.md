# GSB Bugfix Task
## 题面
网关按 cookie 名字把请求路由到不同后端，最近出了串号事故。带主机前缀的 cookie 明明规定了不许写域属性，代码还是接受了带域的版本；安全前缀的 cookie 没带安全传输标志也照发；跨站模式下没配安全标志，浏览器直接丢弃，服务端却按 cookie 存在处理；域属性写成公共后缀仍然能设置；同名 cookie 挂在两个不同路径下，读取时没有按最长路径优先，拿到了旧值；带引号的值把引号一起带进了业务字段；有效期和绝对过期时间同时出现时取了错的那个；过期时间格式非法被当成会话 cookie；值里有逗号，解析时被拆成两个 cookie；单个 cookie 超过四KB仍然写入；删除时没有同时匹配路径和域，删不掉；端口被写进域属性；名字大小写不同被当成两个 cookie；属性之间用分号加空格和只用分号解析结果不同。cookie_prefix_rules.py 的 CookiePrefixRules 要提供一套严格的解析与写入：解析时按规范切分，引号内的分隔符不切，同名同路径只保留一个；写入时校验名字和前缀规则，主机前缀要求安全传输、路径为根、无域属性，安全前缀要求安全传输；跨站模式必须同时有安全标志；域属性拒绝公共后缀和空标签；有效期与绝对时间按规范优先级取，非法时间拒绝；单条和总量都有上限；删除必须给出匹配的路径与域；输出属性顺序稳定，解析再写回保持语义。test_cookie_prefix_rules.py 的十五条断言眼下全部失败，覆盖前缀、域属性、公共后缀、路径优先、引号、两种有效期、非法时间、逗号、大小上限、删除、端口、名字大小写、属性空格、总量和往返一致。

## 运行方式
```bash
python -m pytest tests -q
```
