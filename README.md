# GSB Bugfix Task
## 题面
地形编辑器把弹孔和脚印烘进地表贴图后，斜坡上的孔洞被拉成长条，图集接缝处还会漏出相邻地块的颜色。投影只按平面坐标平移，没有用地形朝向做背面判断，坡背面也烘了进去；覆盖到三角形边界时没有裁剪，越过 UV 岛写进隔壁地块；图集接缝没有留边，采样时吸到背景色；同一位置叠了三张图案，烘焙顺序按提交时间，每次运行结果不同；边缘的半透明像素直接盖上去，没有按阿尔法混合；图案尺寸和地形密度不匹配，近处糊远处锐；平面坐标到 UV 的变换在跨地块时没有加偏移；地面朝向与投影方向接近平行时没有淡出，边缘一条硬线。decal_projection.py 的 DecalBakePlanner 要产出可复现的烘焙任务：把投影盒变换到每个地块的 UV 空间，按三角形裁剪出覆盖区域；背面和夹角超过阈值的片元剔除，边缘按夹角和距离淡出；写入前按阿尔法混合，保留原地表细节；图集接缝留出配置的边距，越界写入拒绝；多张图案按优先级和稳定编号排序，同优先级按创建序号；密度不一致时先重采样；跨地块的 UV 偏移逐块计算；输出每块的任务、覆盖矩形、混合权重和告警。test_decal_projection.py 的十五个断言全部报错，压斜坡拉伸、背面剔除、三角形裁剪、接缝漏色、叠加顺序、阿尔法、密度、UV 偏移、夹角淡出、边距、越界、优先级、重采样、任务输出和结果复现。

## 运行方式
```bash
python -m pytest tests -q
```
