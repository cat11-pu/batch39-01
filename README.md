# GSB Bugfix Task
## 题面
权限变更审批现在只给一个“新增若干条”的总数，安全委员会根本没法审。通配符展开后实际增加了哪些动作没人算；被删掉的语句和新增的语句混在一起，看不出净变化；拒绝语句和允许语句同时存在时，差异没有体现拒绝压过允许；带条件键的语句被当成无条件，风险被低估；资源地址里的大写字母、斜杠和通配符没有归一，同一个资源出现两种写法；只写排除动作的语句被当成空语句跳过；主体从用户组换成角色，差异显示成删除加新增而不是替换；策略版本升级带来的隐式变化没有标注；重复语句被计了两次；语句顺序变化被当成实质变更；未知动作没有对照表，直接放行；动作名的大写字母不同被当成两个动作；范围收窄的变更和范围扩大的变更用了同一种颜色；高风险动作没有另列一栏；审批快照每次字段顺序都不一样。permission_diff_plan.py 的 PermissionDiffPlan 要产出可审的净变更：先把策略解析成语句集合，展开通配符和排除动作，资源地址折成小写、合并重复斜杠、保留通配语义；按主体、动作、资源、条件四元组做集合差，区分新增、删除、修改；拒绝语句单独成组并标注覆盖关系；条件键的增删要逐项列出；主体类型变化标成替换；同一策略版本内的重复语句先去重；顺序变化不算变更；未知动作列进待确认清单而不是直接放行；高风险动作按内置清单标记；结果按主体、动作、资源固定次序输出，并给出变更前后的有效权限数。test_permission_diff_plan.py 里十五项检查目前没有一项通过，压通配符展开、净变化、拒绝压过允许、条件键、资源写法归一、排除动作、主体替换、版本升级、重复语句、顺序变化、未知动作、字母大小写、范围收窄、高风险栏目和固定输出次序。

## 运行方式
```bash
python -m pytest tests -q
```
