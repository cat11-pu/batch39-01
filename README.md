# GSB Bugfix Task
## 题面
运维平台让用户填一段参数，后端拼成 shell 命令去执行巡检脚本。上周有人在一个备注参数里写了分号加删除命令，虽然被值班同学拦住了，但这事必须从根上修。现在的拼接只给含空格的参数加引号，美元符号、反引号、换行、通配符全都原样带进去；空字符串直接消失，参数个数对不上；以减号开头的值被当成选项；单引号自己不会转义；NUL 字节让底层调用截断；等号开头的值被误认为环境变量赋值；中文和表情符号在某些 locale 下被拆坏；同一个参数重复引用时引号嵌套出错。sink_arg_quoter.py 的 SinkArgQuoter 要做两件事：把参数列表安全地拼成一条 POSIX shell 命令，以及把这条命令解析回参数列表。拼接时每个参数单独用单引号包住，内部的单引号按标准写法转义，空串保留，换行和控制字符要么拒绝要么显式转义；解析回来必须和原列表逐项相等，包括空串和特殊字符。以减号开头的值不做特殊处理，由调用方决定是否加选项终止符；NUL 一律拒绝。test_sink_arg_quoter.py 的十五条断言现在全部失败，覆盖空格、单引号、双引号、美元符号、反引号、换行、通配符、空串、减号开头、等号开头、中文、表情符号、NUL、往返一致和重复拼接幂等。

## 运行方式
```bash
python -m pytest tests -q
```
