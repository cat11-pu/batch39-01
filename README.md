# GSB Bugfix Task
## 题面
设置界面的九宫格按钮在超宽屏上被拉成了面包：四个角跟着整体缩放，圆角变成椭圆；左右边框被横向拉伸，花纹糊成一片；中间区域本来应该平铺，代码却用了拉伸，纹理细节全丢；边框宽度按百分比算，窗口变大后边框粗得离谱；图集里取子区域时少减了一个像素，边缘出现一条杂色；高分辨率屏下边框按物理像素算，和逻辑像素对不上；宽度小于左右边框之和时，输出宽高变成负数；高度刚好等于上下边框之和时，中间区域高度为零却还在生成顶点；水平翻转后左右边框互换了位置，但纹理坐标没换；旋转九十度后上下左右边框对应关系全错；九宫格退化成三宫格时，中间行被重复计算；连续调整窗口大小一千次后顶点数一路上涨。nine_slice_scale.py 的 NineSliceScale 要按边框像素而不是百分比切分：输入源矩形、四边边框宽度和目标矩形，先校验边框非负且不超过源尺寸，目标尺寸小于边框和时按最小尺寸夹紧并给出标记；四个角保持原尺寸不缩放，上下边只横向平铺或拉伸，左右边只纵向处理，中间区域按配置平铺或拉伸；图集坐标按源矩形加边框计算，边界像素不越界；翻转和旋转通过交换边框与纹理坐标实现，不重新采样；三宫格模式把中间行或列合并；输出顶点数只与模式有关，不随目标尺寸增长；连续调用不累积状态。test_nine_slice_scale.py 的十五个用例现在全部失败，覆盖角缩放、边框拉伸、中间平铺、百分比、图集偏移、高分辨率、负尺寸、零中间区、水平翻转、旋转、三宫格、顶点增长、边框超限、最小夹紧和重复调用。

```bash
python -m pytest tests -q
```
